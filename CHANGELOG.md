# omicOS 更新记录总览 / Changelog Overview

omicOS 由三个相互独立发版的组件组成,版本号不共用。请查看各自的更新记录:
omicOS ships as three independently versioned components. See each component's changelog:

- **内核 / Kernel** — [`changelogs/core.md`](changelogs/core.md)
- **网页端 / Web UI** — [`changelogs/webui.md`](changelogs/webui.md)
- **桌面 App / Desktop** — [`changelogs/desktop.md`](changelogs/desktop.md)

> 想第一时间收到新版通知?点右上角 **Watch → Custom → Releases**。GitHub Releases 跟随**内核(kernel)**版本线,发布时会通知你;网页端与桌面端的完整记录见上面各自的 changelog。
> Want to be notified of new releases? Click **Watch → Custom → Releases** at the top right. GitHub Releases track the **kernel** version line; the full web-UI and desktop history lives in the changelogs above.

本仓库仅含发布说明,不含源代码(见 [`NOTICE.md`](NOTICE.md))。
This repository contains release notes only, no source code (see [`NOTICE.md`](NOTICE.md)).
