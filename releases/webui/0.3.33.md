## 中文

- 新增 Bot（Beta）：左侧栏多了 Bot 入口，可以创建长期在线的 Bot，和它们私聊、拉群，Bot 有自己的记忆，也能接入 IM 聊天。此项需配合新版 Core。
- 已购课程可以按章节学习，章节资源随学随取。此项需配合新版 Core。
- 定时消息里的文件路径保持原样；切换对话时输入框不再消失；图库导入的新图片排在最前。
- Core 重新连接期间对话历史可以恢复；商店页面保持布局和发票状态。

## English

- New Bot (Beta): a Bot entry in the left rail for long-lived bots you can chat with one-on-one or in groups, each with its own memory, and connect to IM chats. Requires the matching Core update.
- Purchased courses can be studied chapter by chapter, with each chapter's resources fetched as you go. Requires the matching Core update.
- File paths in scheduled messages are kept as written; the composer stays visible when switching conversations; newly imported gallery images appear first.
- Conversation history recovers while Core reconnects; the store page keeps its layout and invoice state.
