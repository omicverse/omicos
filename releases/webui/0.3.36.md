## 中文

- Bot 详情新增「用量」：看它今天、近 7 天、近 30 天调用了多少次模型、用了多少 token，按模型拆开，也能和其他 Bot 比一比。此项需配合新版 Core。
- 群聊可以设目标：管理员和你商量好目标与完成标准，拆成几个阶段交给成员，每个阶段验收通过才进入下一个；群顶部显示进行到哪一步，可以开始、暂停、继续或停止。此项需配合新版 Core。
- 「消息渠道」里可以为单个聊天打开「允许在这里回复批准」：要批准的操作会以带编号的卡片发到聊天里，回复「批准 N」即可。只建议在只有你自己的私聊里打开。此项需配合新版 Core。
- Bot 功能里的中文名称和提示换成了更常用的说法；Bot 回答里用本地路径引用的图片现在能正常显示。
- 内核忙的时候，变量面板会保留已有的变量，等内核空下来再刷新，不再卡住。

## English

- A bot's details have a Usage tab: its model calls and tokens today, over 7 and 30 days, by model, next to the other bots. Requires the matching Core update.
- Group chats can have a goal: the admin agrees it with you, splits it into stages for the members, and checks each stage before the next one starts. The top of the group shows where it stands, with start, pause, resume and stop. Requires the matching Core update.
- In the IM tab you can let one chat answer approvals: each approval arrives there as a numbered card, and replying "approve N" decides it. Turn it on only for a chat that is yours alone. Requires the matching Core update.
- Clearer Chinese wording across the bot feature; pictures a bot links by a local path now show in its answers.
- While the kernel is busy, the variables panel keeps what it has and refreshes once the kernel is free, instead of waiting.
