## 中文

- 模型：刷新时优先使用服务商自己公布的模型列表，并记录上下文长度的来源；支持阿里云 Token Plan 的 Qwen 模型、Moonshot K3.1 的推理与上下文，以及官方 Mistral 上 Large 4 的推理强度；已下线的模型在官方接口上会被明确拒绝；免费额度和 Console 可用的模型按最新规则执行。
- 中转服务的余额可以自动发现。
- 云登录过期时保留已有的付费权益，沿用原来的授权与宽限规则。

- 远程：中继重新连接卡住时能自动恢复；SSH 先选定运行环境再检查更新，取消的通道会被释放。

## English

- Models: a refresh prefers the provider's own model list and records where each context length came from; Qwen models on Alibaba Token Plan, Moonshot K3.1 reasoning and context, and Large 4 reasoning effort on the official Mistral route are supported; retired models are refused clearly on their official endpoints; free-quota and Console-eligible models follow the current rules.
- Relay service balances are discovered automatically.
- When the cloud login expires, paid access is kept under the existing entitlement and grace rules.
- MCP: every nvm installation is checked from newest to oldest, so Node.js 24 is no longer reported missing by mistake; the PATH in a server's configuration is respected.
- Remote: a stalled relay reconnection recovers on its own; SSH picks the runtime before checking for updates, and cancelled channels are released.
