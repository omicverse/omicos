## 中文

- Bot 可以交给本机的编程 Agent 运行，比如 Claude Code、Codex CLI、Gemini CLI、OpenCode，用它们各自的登录和套餐；聊天、任务、审批和记忆照常工作。
- 连接器：连接一次 GitHub、邮箱（IMAP/SMTP）或远程 MCP，Bot 就能使用；凭据加密存在本机，发邮件始终要你批准。
- Bot 群聊可以设目标，按阶段推进，每个阶段由一个成员负责，验收通过才进入下一阶段。
- 在你允许的 IM 聊天里，直接回复「批准 N」或「拒绝 N 原因」就能处理审批。
- Bot 之间发消息可以附带文件和文件夹；每个 Bot 的模型用量可以单独查看。
- Bot 做完实际工作后会记住要点，也能查到自己在其他聊天里做过的事；没有指定头像的 Bot 会从头像库得到一个形象。
- 内核忙时，变量面板的检查直接返回，不再等待。

## English

- A bot can run on a coding agent on this computer, such as Claude Code, Codex CLI, Gemini CLI or OpenCode, using that agent's own sign-in and plan; chats, tasks, approvals and memory work as before.
- Connectors: connect GitHub, a mailbox (IMAP/SMTP) or a remote MCP server once and your bots can use it. Credentials are stored encrypted on this computer, and sending mail always asks for your approval.
- Bot group chats can have a goal worked through in stages, each owned by one member and checked before the next begins.
- In an IM chat you allow, reply "approve N" or "deny N reason" to decide an approval.
- Bots can attach files and folders to messages to each other, and each bot's model usage can be viewed on its own.
- Bots remember the key points after real work and can look up what they did in their other chats; a bot without a chosen picture gets one from the avatar library.
- While the kernel is busy, variable-panel checks return right away instead of waiting.
