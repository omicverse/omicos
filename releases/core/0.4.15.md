## 中文

- **新增 `.omicos` 复现工作区容器**——支持 license 校验、解密与导入,便于打包与分享可复现的分析工作区。
- **Figure Studio:接入 Tavotto 宿主并持久化画布**;回放 sidecar 绑定到其捕获的图。
- **工具调用更稳**——被切片的参数流不再产生成千上万个无名调用;被输出预算截断的调用不再被误报。
- **委派与记忆**——因循环被拒的委派不再反复发出;绑定项目的对话不再收到用不上的记忆;agent 名单完整送达选择器。
- **notebook 与解释器**:路径定位、输出目录解析与系统错误码更稳健。
- **一批修复**:双身份回执应答、订阅计划上下文回退、保留失败委派回执、技能恢复诊断。

## English

- **New: `.omicos` reproduction-workspace container** — license verification, decryption, and import, for packaging and sharing reproducible analysis workspaces.
- **Figure Studio: Tavotto host integration with canvas persistence**; replay sidecars are bound to the figure they captured.
- **More robust tool calls** — a sliced argument stream no longer becomes thousands of unnamed calls; a call truncated by the output budget is no longer misreported.
- **Delegation & memory** — delegations rejected for a cycle are not reissued; a project-bound conversation no longer receives memory it cannot use; the full agent roster reaches the selector.
- **Notebook & interpreter**: more robust path resolution, output-directory handling, and stable system error codes.
- **A batch of fixes**: dual-identity receipt requests, subscription-plan context fallback, preserved failed-delegation receipts, and skill-recovery diagnostics.
