## 中文

- **新增 Paper2Agent**:把一篇论文的 MCP 包作为服务器安装,并可分享给实验室(lab)团队使用。
- **新增:用 @ 提及 MCP 服务器**,并可为服务器设置显示名。
- **修复:分析记录(trajectory)的写入对取消操作安全**,并会正确向上报告 I/O 错误。
- **一组修复**:拒绝空的模型补全;恢复文本形式的工具调用;修正工具结果消息的名称;保留 Token 计划的推理档位。
