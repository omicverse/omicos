## 中文

- Bot 运行代码前怎么问可以设置：每次都问、每个对话同意一次后不再问，或者不问；新建的 Bot 默认每个对话问一次。在 IM 里回复「本对话都允许 N」可以一次放行整个对话。
- Bot 修复：自动续跑的回合会接着做上一回合没完成的清单；没有看图能力时改用代码和数据检查图表；优先用你指定的输出文件夹；群目标进行中不会提前叫醒成员；记忆里不再把别的 Bot 说的话当成你说的。
- 跨对话、跨回合都能命中模型服务商的缓存，重复计费更少。
- 可以查看 Coding Plan 的额度和账号余额。
- 模型回复中断后能安全恢复；订阅续期遇到临时失败会自动恢复；中文等多字节字符不再被截断；Antigravity 的生成功能恢复。
- SSH 隧道请求不再走代理；命令行输入历史不再记录凭据；远程项目的对话缺失时保留其状态。

## English

- You can set how a bot asks before running code: every time, once per chat, or never; new bots ask once per chat. In IM, replying "allow session N" approves the rest of the chat at once.
- Bot fixes: an auto-continued turn picks up the previous turn's unfinished checklist; without vision, charts are checked through code and data; your chosen output folder comes first; members are not woken early while a group goal is running; memory no longer mistakes another bot's words for yours.
- The model provider's cache hits across conversations and turns, so less is billed twice.
- Coding Plan quotas and account balances can be checked.
- Interrupted model replies recover safely; subscription renewal recovers from temporary failures; Chinese and other multi-byte characters are no longer cut off; Antigravity generation works again.
- SSH tunnel requests bypass proxies; command-line input history no longer stores credentials; a remote project's missing conversation keeps its status.
